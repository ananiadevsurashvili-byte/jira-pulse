Manage your deliverable stats.

This is the JiraPulse admin panel. Connect your Jira account to publish board stats, generate shareable links, and control what your organization can see. Your credentials never leave this browser.

How do I get an API token?
  1. Open id.atlassian.com → API tokens
  2. Click Create API token, give it a name and copy the value
  3. Paste your site address, account email and token above

This admin panel runs fully client-side. Your credentials are stored only in this browser's local storage and sent directly (or via optional CORS proxy) to your Jira site.
