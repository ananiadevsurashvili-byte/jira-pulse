Connect with your Jira API token to get instant delivery insights — how long tasks sit in each status, what shipped in the last 30 days, team throughput and more. Credentials never leave your browser.

How do I get an API token?
  1. Open id.atlassian.com → API tokens
  2. Click Create API token, give it a name and copy the value
  3. Paste your site address, account email and token above

This app runs fully client-side. Your credentials are stored only in this browser's local storage and sent directly (or via optional CORS proxy) to your Jira site.
